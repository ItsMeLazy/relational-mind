# Relational Mind

Experimental prototype exploring relational memory, contextual retrieval,
developmental learning, and brain-inspired information processing.

## Status

Prototype — environment setup complete.

## Current Objective

Build a system that can:

1. Extract concepts from experience.
2. Represent relationships between concepts.
3. Represent grammatical/structural relationships.
4. Store those relationships as relational memory.
5. Eventually retrieve and reason through the resulting network.
